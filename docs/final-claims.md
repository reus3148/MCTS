# 최종 주장 세트

24개 버전이 낸 결과를 **논문·발표에서 실제로 주장할 문장**으로 추린 것입니다.
`docs/research-story.md`가 줄거리이고 `docs/results-reconciliation.md`가 숫자 대조표라면,
이 문서는 **"그래서 뭐라고 쓸 것인가"** 입니다. 논문 초록과 최종 PPT가 여기서 나옵니다.

각 주장에 **수치 · 근거 리포트 · 성립 조건 · 한계 · 심사자가 물을 것**을 붙입니다.
조건이나 한계를 뗄 수 없는 주장은 그 상태로 씁니다.

---

## 0. 한 문장으로

> **현행 NCCN 가이드라인이 최적인지 묻는 비교를 설계했고, 그 비교가 믿을 만해지려면
> 무엇이 필요한지를 수치로 만들었다. 조건 셋은 해결했고, 남은 하나(표준치료의 선언된
> 이득)에 결론 전체가 달려 있음을 보였다.**

이 연구는 **"MCTS가 NCCN보다 낫다/못하다"에 답하지 않습니다.** 답할 수 없다는 것과
**왜 답할 수 없는지**가 결과입니다. 2026-05-26 킥오프에서 프레임을 "가이드라인 검증
PoC"로 좁힌 결정과 일치합니다 — 산출물은 "이기는 MCTS"가 아니라 "믿을 수 있는 비교".

---

## A. 방법론 주장 (이 연구의 핵심 기여)

### A1. 효용 격차의 **81%** 는 우리가 환경에 써넣은 두 미선언 채널에서 왔다

| | |
|---|---|
| **수치** | 보상모형의 치료 계수 **40.3%** (z = −5.37) + 선언된 치료 비용 **41%** (남은 격차의 69.1%, z = −11.9) |
| **근거** | `reports/reward-confounding-v1.4`, `reports/channel-decomposition-v1.5` |
| **조건** | 환자 40명 · 시드 12 · 예산 1024 · 아형 균등 표본 |
| **검증** | 영대조 통과 — 두 채널을 모두 끄면 격차 **+0.0013** (허용치 0.005) |

관찰자료에서 학습한 Cox 모형의 치료 계수가 NCCN을 깎고 있었고(미선언 채널), 표준
항암·표준 내분비·국소 방사선은 **선언된 이득이 정확히 0인데 비용만 청구**되고 있었습니다.
둘 다 우리가 넣은 것이고, 둘 다 한쪽 정책에만 작용했습니다.

> **심사자가 물을 것**: "그럼 원래 숫자는 틀린 거냐" → **네. 그래서 철회하고 다시
> 쟀습니다.** v0.2~v1.2의 수치는 옛 환경의 기록으로 보존하되 인용하지 않습니다.

### A2. 자유 탐색 정책은 시뮬레이터의 **선언**을 최적화한다 — 잘 탐색할수록 선언에 충실해진다

| | |
|---|---|
| **수치** | 예산 256 → 1024에서 격차 +0.0212 → **+0.0314** (짝지은 +0.0102 [+0.0027, +0.0176]) |
| **근거** | `reports/budget-scaling-v0.4` |

예산을 올리면 격차가 커집니다. 이것은 "MCTS가 더 낫다는 증거가 강해졌다"가 **아니라**
**"MCTS가 우리 합성 가정을 더 잘 활용한다"** 는 뜻입니다. MCTS는 시뮬레이터의 목적함수를
직접 최적화하고 NCCN 정책은 그렇지 않으므로, **가정이 틀리면 잘 탐색할수록 더 틀립니다.**

이것이 A1·A3와 합쳐져 이 연구의 방법론적 결론을 만듭니다.

### A3. 새 결정 지점은 **판돈 × 상태 의존 × 해상도** 가 다 있어야 값을 가진다

| 버전 | 무엇을 열었나 | 빠진 다리 |
|---|---|---|
| v1.8 | 재발 시 구제 결정 | 지평 인공물 (판돈이 지평에 잘림) |
| v1.9 | 말기 가치로 지평 수정 | 상태 의존 (98.7%가 같은 답) |
| v2.0 | 어디서 갈리는지 측정 | 상태 의존 (환자 간 퍼짐 **0.01**) |
| v2.4 | 상태를 세 등급으로 분할 | **해상도** (정보가치 **0.00070** 대 잡음 **0.02** = 1/28) |

네 번의 시도가 각각 다른 다리에서 넘어졌고, **v2.4가 벽의 이름을 찾았습니다**:
**문제는 상태의 해상도가 아니라 채널의 판돈**입니다. 구제 채널 전체 판돈은 0.0757이고
등급 조건부 몫은 **0.9%** 입니다.

> **재사용 가능한 절차**: 새 결정 지점을 열기 전에 **탐색 없이** 환경의 산술로 지도를
> 그려 세 다리를 확인합니다. 5초짜리 계산이 40분짜리 탐색을 대신합니다.

## B. 결과 주장

### B1. 현재 환경에서 효용 격차는 **+0.0199** — 조건 셋을 떼고 쓸 수 없다

> **+0.0199** (예산 1024 · 환자 40명 · 시드 12 · **아형 균등 표본 · 치료 중립 보상모형**)
> ① 실제 아형 구성으로 표준화하면 **+0.0136**
> ② 아형에 따라 **3.7배** 갈린다 (HR+/HER2− +0.0136 ~ HR−/HER2+ +0.0503)
> ③ **표준치료의 선언된 이득이 문헌값의 44.5% 미만일 때만** 성립 (그 위에서는 부호가 바뀜)

| | |
|---|---|
| **근거** | `reports/cohort-replication-v1.2`, `reports/reward-confounding-v1.4`, `reports/benefit-tipping-v2.1` |
| **한계** | 40명 중 1명이 음수 — **"모든 환자에게 낫다"고 쓰지 않습니다** |

꼬리표 없이 +0.0199만 쓰는 것은 **금지**입니다(2026-09-05 결정). 독자가 모집단 평균으로
읽습니다.

### B2. 표준치료 이득을 문헌값의 **44.5%** 만 선언해도 결론이 뒤집힌다

| 선언 강도 | 효용 격차 |
|---:|---:|
| 0.00 (현재 config) | **+0.0199** |
| 0.25 | +0.0049 |
| **0.445 (전환점)** | **0** |
| 1.00 (문헌 끝점) | **−0.0061** |

| | |
|---|---|
| **전환점의 재발 위험비** | 항암 **0.880** · 내분비 **0.797** · 방사선 **0.734** |
| **근거** | `reports/benefit-tipping-v2.1` |
| **한계** | **끝점 위험비는 EBCTCG 메타분석의 자릿수로 적은 선언값이고 원문 대조 대기 중.** 그래서 전환점을 **분율과 위험비로 함께** 보고합니다 — 끝점이 바뀌면 분율만 다시 계산됩니다 |

표준치료가 재발을 **12~27%만** 줄이면 되는 크기입니다. 임상적으로 그게 있느냐는
논쟁거리가 아닙니다. **그러므로 헤드라인은 "표준치료가 아무 소용이 없다"는 우리 선언에
전적으로 의존합니다.**

> **이것이 이 연구의 가장 중요한 한 줄입니다.** 값을 못 정했지만 **결론이 그 값에 얼마나
> 매달렸는지**는 정했습니다.

### B3. 순차적 방법의 이점은 이 환경에서 **측정되지 않는다** (검정력과 함께)

| | |
|---|---|
| **수치** | 응답 채널을 계획자에게서 완전히 가려도 격차 변화 **−0.00037** (z = −0.29) |
| **검출 가능 최소 차이** | **0.00359** — 관측값이 MDE의 **10%** |
| **근거** | `reports/closed-loop-value-v1.7` |

**"차이 없음"이 아니라 "검출할 수 없었음"** 입니다. 그리고 이유를 알고 있습니다 —
우리 환경은 응답 신호를 **에피소드의 20.8%에서 단 한 번** 줍니다(C2 참조).

## C. 실제 자료 주장

### C1. 실제 진료는 **적응한다** — 두 독립 코호트가 같은 수를 냈다

| 자료 | 코호트 | 판독 | 진행 뒤 90일 내 치료 변경 | 안정 뒤 | 비율 |
|---|---:|---:|---:|---:|---:|
| GENIE BPC | 1,130명 | 진행 5,242 / 안정 5,963 | **71.3%** | 29.5% | **2.42배** |
| MSK-CHORD | 5,368명 | 진행 7,876 / 안정 18,481 | **66.8%** | 27.6% | **2.41배** |

| | |
|---|---|
| **시간 위약대조** | MSK-CHORD: 진행 **+0.294** 대 안정 **−0.050**(안정 판독 *뒤*가 *앞*보다 치료 변경이 적다 — "유지하라는 신호") |
| **검정력** | 환자 군집 z = **+33.2**, MDE 0.0288 (관측 차이가 MDE의 11.9배) |
| **근거** | `reports/genie-bpc-profile-v1.6`, `reports/msk-chord-profile-v2.2` |
| **한계** | **보정하지 않은 연관**이고 적응증에 교란되어 있습니다. "기록된 대국에 적응이 들어 있다"까지만 말합니다 |

기관·큐레이션 방식·판정 라벨 체계가 다른 두 릴리스가 같은 수를 냅니다. **폐루프 전제는
관찰적으로 지지됩니다.**

### C2. 우리 환경은 적응 기회를 **3배** 과소 모형화한다

| | 우리 환경 (v0.5) | 실제 (진단 90일 내 진입군, n=1,669) |
|---|---:|---:|
| 적응 기회 중앙값 | **1** | **3** |
| 자리가 있는 환자 | **20.8%** | **66.0%** |

| | |
|---|---|
| **근거** | `reports/msk-chord-profile-v2.2` |
| **보수적 선택** | 전체 코호트로는 중앙값 5·85.2%지만 인용하지 않습니다 — 진단→시퀀싱 p75가 1,905일이라 코호트의 4분의 1은 5년 창이 닫힌 뒤 기록에 들어옵니다 |

> **B3의 영은 MCTS에 대한 진술이 아니라 우리 환경에 대한 진술입니다.**

### C3. 기록된 진료는 **수행능력에 반응하지 않는다** (검출 한계 아래)

| | |
|---|---|
| **수치** | ECOG 악화 뒤 90일 내 치료 중단 **14.7%** 대 호전 뒤 **13.3%** — 격차 **+1.3%p** |
| **검출 가능 최소 차이** | **3.0%p** (관측값이 MDE의 44%) |
| **용량-반응** | 없음 — 1단계 +1.5%p → 4단계 **−13.3%p** (뒤집힘) |
| **자격 게이트** | **반대 방향** — ECOG≥2에서 항암이 8.1%p 더 많고 **Stage 1-3·Stage 4 양쪽에서 유지** |
| **근거** | `reports/ecog-state-v2.3` |

다만 **ECOG는 질병을 분명히 추적합니다**(진행 판정 후 악화 **2.55배**). 그래서
**예후 변수로는 넣되 자격 게이트로는 넣지 않는다**가 결론입니다.

## D. 우리가 **주장하지 않는** 것 (발표에서 먼저 말할 것)

1. **NCCN이 최적이다 / 최적이 아니다** — 답하지 않습니다. 환경이 표준치료에 이득을
   선언하지 않은 상태에서 나온 격차는 가이드라인에 대한 진술이 아닙니다(B2).
2. **MCTS가 임상적으로 더 낫다** — 효용은 우리가 정의한 합성 척도이고, MCTS는 그
   척도를 직접 최적화합니다(A2).
3. **어떤 치료 전략도 권고하지 않습니다.** 이 연구는 의사결정 지원 도구가 아닙니다.
4. **실제 진료의 적응이 결과를 개선한다** — C1은 보정하지 않은 연관입니다.
5. **외적 타당성** — METABRIC(1970~90년대 영국·캐나다), GENIE BPC·MSK-CHORD(미국
   시퀀싱 의뢰 코호트). 어느 것도 현재 한국 환자를 대표하지 않습니다.
