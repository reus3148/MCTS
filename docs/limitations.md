# 한계 통합

리포트 22곳의 한계 절을 모아 **버전 순서가 아니라 심각도 순으로** 다시 배열했습니다.
각 항목에 **무엇을 위협하는가**와 **어떻게 완화했는가**를 붙였습니다.

> CLAUDE.md의 규칙: **한계는 문서 끝이 아니라 해당 결과 가까이에** 적는다. 이 문서는
> 논문 §4.3의 원본이고, 개별 리포트의 한계 절은 그대로 둡니다 — 거기서 읽는 사람은
> 그 결과 옆에서 읽어야 하니까요.

**등급 1이 가장 위험합니다.** 등급 1만 읽어도 이 연구를 어디까지 믿을지 정할 수 있게
썼습니다.

## 등급 1 — 결론을 바꿀 수 있는 것 (4건)

### 1.1 표준치료의 선언된 이득이 **0**이다

| | |
|---|---|
| **위협** | 헤드라인 +0.0199의 **부호** |
| **크기** | 문헌값의 **44.5%** 만 선언해도 뒤집힌다 (전환점 재발 위험비 항암 0.880·내분비 0.797·방사선 0.734) |
| **완화** | 값을 고르지 않고 **다이얼**로 만들어 전환점을 보고 (v2.1) |
| **남은 것** | 끝점 위험비가 **EBCTCG 자릿수로 적은 선언값**이고 원문 대조 대기 중. 그래서 전환점을 **분율과 위험비로 함께** 보고 — 끝점이 바뀌면 축만 다시 눈금이 매겨진다 |
| 출처 | v1.5, v2.1 |

> **이 연구의 모든 수치 중 가장 중요한 한계입니다.** 헤드라인을 인용하는 모든 자리에
> 이 조건을 함께 적습니다.

### 1.2 환경 전체가 **합성 가정** 위에 있다

| | |
|---|---|
| **위협** | 모든 수치 |
| **내용** | 전이 확률·치료 효과·효용 가중치를 **우리가 정했다.** 임상 추정치가 아니다 |
| **완화** | v0.3·v0.8·v1.0의 민감도 분석, v2.1·v2.4·v2.5의 다이얼 |
| **그래도** | 민감도는 **우리가 고른 범위 안에서만** 흔든다. 범위를 바꾸면 순위도 바뀐다 (v1.0) |
| 출처 | v0.2 이후 전부 |

### 1.3 교란요인 목록이 **불완전**하다 — 근거가 셋

| 근거 | 무슨 일이 있었나 |
|---|---|
| v0.7 | **수술 유형을 넣자 방사선의 겹침이 깨졌다** (최악 \|SMD\| 0.086 → 0.234). 넓은 겹침은 균형이 아니라 **측정하지 않았다는 신호**였다 |
| v1.3 | **음성대조가 실패했다.** ER 음성 환자의 내분비치료에서 위험차 **−0.139** [−0.235, +0.043] — 효과가 없어야 할 곳에서 효과가 보인다 |
| v1.4 | **보상모형의 치료 계수 부호가 틀렸다.** 관찰자료에서 "항암 받으면 더 빨리 사망"을 학습했다 |

| | |
|---|---|
| **위협** | 인과 추정(v0.6·v0.7)의 식별, 보상모형의 타당성 |
| **완화** | 인과 파트를 헤드라인에서 분리. 보상모형은 **예후만** 담당하게 중립화 (v1.4) |
| **E-value** | 1.59 — 보통 크기의 미측정 교란이면 결과를 뒤집는다 (v0.6) |

### 1.4 외적 타당성이 **없다**

| 자료 | 제약 |
|---|---|
| METABRIC | **1977~2005년 영국·캐나다.** 당시 항암 적응증·요법이 현재와 다르다 |
| GENIE BPC · MSK-CHORD | 미국 **단일 기관 시퀀싱 의뢰** 코호트 |
| 공통 | **어느 것도 현재 한국 환자를 대표하지 않는다** |

**증거**: NCCN 일치율이 항암 **39.8%** 다(HR+/HER2+는 25.0%). 당시 환자들이 현행
가이드라인과 다르게 치료받았다는 뜻이다(`docs/nccn-policy-spec.md` §4).

> 헤드라인 표집을 **아형 균등**으로 고정한 이유이기도 합니다 — 표준화의 기준이 될
> METABRIC 분포가 이미 외적 타당성이 없다고 선언한 분포라서요 (2026-09-05 결정).

## 등급 2 — 해석을 제한하는 것 (7건)

### 2.1 비대칭 채널 — NCCN이 쓰지 못하는 수준이 있다

`intensified` 항암 · `extended` 내분비 · `neoadjuvant` 시점을 **NCCN 정책은 한 번도 쓰지
않는다.** 그 수준에만 이득이 붙으면 **MCTS 전용 채널**이다 — v1.5가 격차의 **41%** 로
측정. `tests/test_nccn_policy_spec.py`가 이 사실을 고정한다.

**단, 수용체 자격은 비대칭이 아니다** — HR 음성 환자의 내분비 제외는 두 정책에 똑같이
적용된다.

### 2.2 중립화는 **임시 처방**이다

치료 계수를 0으로 두면 환경에 **자료에서 온 치료 효과가 전혀 없게** 된다. "치료 계수가
교란됐다"는 판단 자체도 자료가 아니라 우리가 내린 것이다. C-index가 0.666 → 0.656으로
떨어지는데, 치료 계수가 예측력을 **조금은** 갖고 있었다는 뜻이다. (v1.4)

### 2.3 부정 결과의 검정력 — 네 곳에서 검출 한계가 크다

| 결과 | 관측값 | MDE | 관측/MDE |
|---|---:|---:|---:|
| 폐루프 적응의 몫 (v1.7) | −0.00037 | 0.00359 | **10%** |
| 결정 지점의 값 (v1.8) | — | 격차의 14% | — |
| 결정 지점의 값 (v1.9) | — | 격차의 27% | — |
| 결정 지점의 값 (v2.0) | — | 격차의 19.5% | — |
| ECOG → 치료 중단 (v2.3) | +0.0135 | 0.0303 | **44%** |

> **"차이 없음"이 아니라 "검출할 수 없었음"입니다.** 각 MDE보다 작은 효과는 배제되지
> 않습니다.

### 2.4 인과 파트는 **단일 시점** 추정이다

v0.6·v0.7의 IPW·AIPW는 **동적 전략 비교가 아니다.** 프로토콜이 요구하는 순차적 비교와
다른 대상을 재고 있다.

### 2.5 Time zero가 근사다 → immortal-time 위험

METABRIC에 치료 시작일이 없어 **진단 시점으로 갈음**했다. (v0.6, v0.7)

### 2.6 트리밍으로 **모집단이 바뀐다**

겹침 구간만 보면 1,354명 중 **515명**. 편의가 아니라 필요였지만(트리밍 없이 가중하면
최악 \|SMD\|가 1.13 → **2.19**로 악화되고 유효표본이 24명으로 붕괴), **추정 대상이
바뀐 사실**을 명시한다. (v0.6)

### 2.7 블라인드가 완전하지 않다

v1.7의 "완전 블라인드"는 **기댓값 대입**이지 진짜 정보집합 최적화가 아니다. 계획자가
자기 수술 선택 결과(`state.surgery`)는 여전히 본다. v1.8의 위임(D)도 같은 성격이다.

## 등급 3 — 통계적 정밀도 (4건)

### 3.1 표본 40명 — 순위는 **그룹으로만** 말한다

겹치지 않는 20명 두 코호트 간 민감도 순위 Spearman이 **+0.03**이었다(v1.2). 합산 40명에서
상위 2개가 가치판단이고 \|z\| ≥ 2도 그 둘뿐이지만, **1·2위 CI가 겹쳐 순서는 말할 수 없고
3~6위는 인용 불가**다.

### 3.2 재발이 **8.7%** 뿐이다

추적 중 결정을 다루는 분석(v1.8~v2.5)의 유효 표본이 그만큼 작다.

### 3.3 음성대조 자체가 n = 270, 구간 폭 0.28

"편의가 −0.139다"가 아니라 **"이 설계로는 편의를 배제할 수 없다"** 까지만 말한다. (v1.3)

### 3.4 일부 초기 분석은 표본·시드가 작다

v0.8은 **3시드·8명**(격자 27셀 때문), v0.7의 부트스트랩은 **500회**(AIPW가 반복마다 세
모형을 적합). 이 값들은 **다른 실행과 절대 수준을 비교할 수 없다.**

## 우리가 **철회한** 것 (4건)

한계와는 다릅니다 — **한때 보고했다가 틀렸다고 확인한 것**들입니다.

| 철회한 주장 | 무엇이었나 | 왜 틀렸나 |
|---|---|---|
| **격차의 부호가 가정에 따라 뒤집힌다** (v0.3) | 기준선 −0.0043 | **3시드 잡음.** 같은 8명·같은 예산에서 시드만 12개로 늘리면 +0.0170 (v1.0) |

## 등급 1만 읽는다면

1. 표준치료에 이득을 선언하지 않았고, **문헌값의 44.5%만 줘도 결론이 뒤집힌다**
2. 환경 전체가 **우리가 고른 합성 가정** 위에 있다
3. 교란요인 목록이 불완전하고, **근거가 셋이나 있다**
4. **외적 타당성이 없다** — 어느 코호트도 현재 한국 환자가 아니다

이 넷을 떼고 이 연구의 수치를 인용하면 **읽는 사람이 잘못 읽습니다.**
